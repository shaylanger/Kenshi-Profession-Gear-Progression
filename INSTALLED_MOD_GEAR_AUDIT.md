## Vortex deployment detail

The deployed `.mod` files are symbolic links. UWE's real source file is accessible in Vortex storage and is about 41 MB. GenMod's old Vortex source target referenced by the current symbolic link is no longer present, but its deployed asset tree is still readable.

Therefore:
- we can audit installed assets now,
- we can inspect accessible source `.mod` databases where Vortex sources still exist,
- exact record extraction may require an FCS-aware parser/tool for every mod,
- asset/name corpora are still sufficient to build a strong semantic classifier test set.

## Classifier conclusions from installed mods

### Name/description must be first-class
Third-party mods generally do not contain ProfessionGear-specific metadata. A new item may simply be:
- Green Hat
- Running Shoes
- Worker Rags
- Pickaxe
- Goggles
- Fur Boots
- Umbrella Hat

The classifier must infer plausible roles from normal Kenshi semantics.

### Base item can support multiple professions
Examples:
- generic rags/workwear => Farming, Labouring, Engineering or Cooking depending on wearer/source context,
- plain goggles => Perception, Science, Engineering, Robotics or Turrets depending on context,
- generic boots => usually no profession; names like Running/Scout/Worker can narrow the pool.

### Combat weapon gate
Normal swords/axes/etc. must stay out of profession affixes even if a faction/name contains a profession-like word.

Exception:
- explicitly tool-like weapon-slot items such as a real/modded Pickaxe can be eligible.

### Unique/high-end protection
Meitou/Cross and other protected legendary gear should never be modified.
High-grade weapons on unique named NPCs are also protected by default.

### Exact ID rules remain useful
IDs are overrides, not the classifier:
- fix false positives,
- force known special cases,
- support total conversions,
- explicitly protect unique mod items.
